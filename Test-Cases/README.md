# Test Cases

Test cases created in TestRail for functional and validation testing of the SauceDemo web application.

## Test Suite: Login

The Login test suite contains **8 test cases** covering positive, negative, and validation scenarios.

### Covered Scenarios

- Successful login with valid credentials
- Login with a locked-out user
- Login with an invalid password
- Login with an invalid username
- Login with an empty username field
- Login with an empty password field
- Login with both fields empty
- Login with credentials entered in uppercase

## Test Case Structure

Each test case includes:

- Title
- Priority
- Preconditions
- Steps
- Expected Result

## Testing Types

The test suite includes:

- Functional Testing
- Positive Testing
- Negative Testing
- Validation Testing

## Tools

- TestRail

- Google Chrome
