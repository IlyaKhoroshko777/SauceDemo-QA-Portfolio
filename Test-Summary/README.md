# Test Summary Report

## Project

**Application:** SauceDemo Web Application  
**Website:** https://www.saucedemo.com/  
**Testing Type:** Manual Web Application Testing

## Objective

The purpose of this project was to practice and demonstrate practical Manual QA skills by testing the main functionality of the SauceDemo e-commerce web application.

Testing focused on critical user flows such as login, product browsing, cart functionality and checkout.

## Test Scope

The following areas were covered:

- Login
- Products page
- Product interactions
- Shopping cart
- Checkout flow
- Form validation
- UI behavior
- Positive and negative scenarios

## Testing Performed

The project included:

- Functional Testing
- Smoke Testing
- Regression Testing
- Positive Testing
- Negative Testing
- UI Testing
- Validation Testing
- Exploratory Testing
- DevTools investigation

## Test Documentation

During the project, the following QA documentation was created:

- **8 Test Cases**
- **53 Checklist Checks**
- **4 Bug Reports**
- DevTools investigation results

## Defects Found

Four defects were documented in Jira while testing the application using the `problem_user` account.

### BUG-01 — Remove Product

The Remove button does not correctly remove a product from the Products page.

**Severity:** Major  
**Priority:** High

### BUG-02 — Add to Cart

Some products cannot be correctly added to the shopping cart.

**Severity:** Major  
**Priority:** High

### BUG-03 — Checkout Last Name Field

Entering data into the Last Name field incorrectly overwrites data in the First Name field.

**Severity:** Critical  
**Priority:** Highest

### BUG-04 — Product Images

Product images are identical and do not correspond to the displayed products.

**Severity:** Major  
**Priority:** High

## Result

The main SauceDemo user flows were analyzed and covered with test documentation.

Testing identified several functional and UI defects affecting product interactions and the checkout process.

The most significant issue was found in the checkout form, where entering data into the Last Name field affected the First Name field.

## Conclusion

The project demonstrates practical Manual QA skills including test documentation creation, test design, defect reporting, functional testing, negative testing and basic investigation using browser developer tools.

All testing artifacts are available in the corresponding folders of this repository.
