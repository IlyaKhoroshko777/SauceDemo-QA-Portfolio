# SauceDemo QA Portfolio

Manual QA testing portfolio project for the SauceDemo e-commerce web application.

## Project Overview

This project demonstrates my practical Manual QA skills using the SauceDemo web application as a testing environment.

The project includes test documentation, bug reporting, browser DevTools investigation, API testing, and basic SQL practice.

## Application Under Test

**SauceDemo** is a training e-commerce web application that includes:

* Login
* Product catalog
* Product details
* Shopping cart
* Checkout flow

## Testing Scope

The following areas are planned to be covered:

* Functional Testing
* UI Testing
* Negative Testing
* Exploratory Testing
* Web testing with Chrome DevTools
* Test Case creation
* Checklist creation
* Bug Reporting
* API Testing
* Basic SQL Testing
