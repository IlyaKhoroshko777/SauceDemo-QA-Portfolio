# SQL Practice

SQL practice project created to demonstrate practical database testing and data analysis skills for Manual QA.

The project uses SQLite and contains an e-commerce test database with users, products, and orders.

## Skills Covered

- Aggregate functions: COUNT, SUM, AVG
- GROUP BY
- HAVING
- JOIN
- Multiple-table JOINs
- LEFT JOIN
- NULL / missing relationship checks
- Sorting and filtering
- QA and business-oriented data analysis

## Project Files

- `database_setup.sql` — creates the SQLite test database and test data
- `sql_queries.sql` — contains 12 practical SQL queries
