# Checklists

Manual testing checklist created for the SauceDemo web application.

## Scope

The checklist contains **53 checks** covering the main user flows:

- Login
- Cart
- Checkout

## Testing Categories

The checklist includes:

- Functional Testing
- Negative Testing
- Validation Testing
- UI Testing

## Checklist Structure

Each checklist item contains:

- ID
- Section
- Category
- Check
- Status

## Execution Status

The checklist was executed manually on the SauceDemo web application.

Status values:

- Pass — actual result matches expected behavior
- Fail — actual result does not match expected behavior
