# Bug Reports

Bug reports created in Jira during manual testing of the SauceDemo web application.

## Scope

The bug reports cover functional, checkout/input, and visual/data-related defects.

## Bug Reports

### BUG-01 — Remove Product

The "Remove" button on the Products page does not remove the product from the cart.

[View Bug Report](BUG-01-Remove-Product.pdf)

### BUG-02 — Add To Cart

The "Add to cart" button does not add some products to the cart.

[View Bug Report](BUG-02-Add-To-Cart.pdf)

### BUG-03 — Last Name Field

Typing in the Last Name field overwrites the First Name field and leaves the Last Name field empty.

[View Bug Report](BUG-03-Last-Name-Field.pdf)

### BUG-04 — Product Images

All product images on the Products page are identical and do not match the corresponding products.

[View Bug Report](BUG-04-Product-Images.pdf)

## Bug Report Structure

Each bug report includes:

- Title
- Environment
- Preconditions
- Steps to Reproduce
- Actual Result
- Expected Result
- Severity
- Priority

- Jira
